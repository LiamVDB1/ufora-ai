# Code of conduct

Ufora AI is an education-focused open-source project. Contributors and users should keep collaboration respectful, technically grounded, and protective of student privacy.

Expected behavior includes constructive review, good-faith disagreement, clear attribution, and extra care around credentials/private academic data.

Unacceptable behavior includes harassment, discriminatory abuse, publishing another person's private student information, intentionally exposing credentials, or using project spaces to facilitate academic misconduct or unauthorized access.

Project maintainers may remove content or participation that violates these expectations. Security/privacy incidents should be handled privately according to `SECURITY.md`, not debated with sensitive details in public issues.
